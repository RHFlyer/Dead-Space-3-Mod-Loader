# Circuits (main set)

All 90 circuits of the game's main circuit set (asset IDs `48CD1CD*-…-4D314E4F-4B554F42`), read live from the
running game (the Seal Store add-on's `dump_circuits=1` debug switch writes the same list to its log). Levels are as
the game shows them; a minus is a penalty. Rate of fire is stored negative for a bonus (shorter time between shots)
and is shown here with the in-game sign. The game also loads 14 copies under other ID families (42CD…, 54CD…) and 5
unnamed ones (33CC…).
